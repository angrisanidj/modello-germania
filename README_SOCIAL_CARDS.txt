MODEL-GENERATED SOCIAL CARDS

This package intentionally contains NO generated PNG card.
The dashboard code renders the landscape 1200x630 and Instagram 1080x1350 cards from the current model state.
GitHub Actions opens the model, waits for the Monte Carlo, calls window.socialCardDataUrl(), writes the two PNG assets, updates card version query strings and commits only when files change.

Files generated by the workflow:
- social-card-bundestag-v2.png
- social-card-bundestag-instagram-v2.png

The workflow runs twice daily, manually, and when index.html / the generator / workflow itself changes.
